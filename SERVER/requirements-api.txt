# api 프로세스 전용 의존성 (슬림 이미지용).
#
# 기존 requirements.txt와의 차이 — 다음은 일부러 뺀다:
#   torch, sentence-transformers : 로컬 임베딩/리랭커용. prod는 원격 provider라 불필요.
#     (EMBEDDING_PROVIDER=openai, RERANKER_PROVIDER=jina → 둘 다 원격 HTTP)
#   playwright, beautifulsoup4, lxml : 크롤링용 → worker(헤비 이미지) 몫.
#   opendataloader-pdf, pdf2image, openpyxl, xlrd, pillow : 첨부파일 파싱 → worker 몫.
#   streamlit : 구버전 UI. 안 씀.
#
# transformers는 남긴다 — langchain(openai·google)이 토크나이저로 요구. torch가 없으면
# transformers가 torch-free로 동작하고, 원격 API 호출에는 토크나이저만 쓰므로 문제없다.
